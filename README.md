# InnovateFund · Blockchain Crowdfunding

แบบฝึกหัดข้อ 5 ระบบบริหารโครงการระดมทุนและจ่ายเงินตามความสำเร็จ บน Ethereum Sepolia

| ผู้ใช้ | ทำอะไรได้ |
| --- | --- |
| บุคคลทั่วไป | ดูโครงการ ยอดรวม เป้าหมาย เวลาที่เหลือ สถานะระยะงาน และประวัติเงินเข้า–ออก |
| เจ้าของโครงการ | สร้างโครงการพร้อมกำหนดงบและรายละเอียดแต่ละ Milestone แล้วส่งหลักฐานเพื่อขอเบิกตามลำดับ |
| ผู้สนับสนุน | เชื่อม MetaMask เพื่อสนับสนุนด้วย Sepolia ETH โหวตอนุมัติ และขอคืนเงินเมื่อเข้าเงื่อนไข |

## กฎการระดมทุนและจ่ายเงิน

- ผลรวมงบของทุก Milestone เป็นเป้าหมายระดมทุน Smart Contract เก็บ ETH และปิดรับเมื่อครบเป้าหมายหรือหมดเวลา
- เมื่อครบเป้าหมาย เจ้าของโครงการเริ่มส่งหลักฐานได้ ผู้สนับสนุนโหวตได้คนละหนึ่งครั้งต่อระยะ โดยน้ำหนักเท่ากับยอดที่สนับสนุน
- เสียงอนุมัติต้อง **เกิน 50%** ของยอดระดมทุนทั้งหมด จากนั้นบัญชีใดก็ได้กด **จ่ายตาม Milestone** และ Contract จะจ่ายเฉพาะงบของระยะนั้นให้เจ้าของเพียงครั้งเดียว
- หากหมดเวลาระดมทุนก่อนถึงเป้า ผู้สนับสนุนขอคืนได้เต็มจำนวน หากโครงการถึงเป้าแต่หมดเวลาส่งหลักฐานหรือหมดเวลาโหวตโดยไม่ผ่าน ให้กดปิด Milestone จากนั้นผู้สนับสนุนขอคืนเงินคงเหลือตามสัดส่วนได้
- หน้าประวัติแสดงยอดรับทุน ยอดจ่ายตาม Milestone และยอดคืน ควบคู่กับสถานะของแต่ละระยะ

## Deploy บน Sepolia

1. เปิด [Remix](https://app.remix.live/) ในเบราว์เซอร์ที่ติดตั้ง MetaMask แล้วใช้ **Files → Create → Upload files** เพื่อเพิ่ม `contracts/InnovateFund.sol`
2. เลือก Solidity **0.8.34** ในแท็บ Compile แล้วกด **Compile**
3. เปิด **Deploy & Run Transactions → Browser Extension → MetaMask** เลือกเครือข่าย **Sepolia** แล้ว Deploy **InnovateFund** โดย **Value = 0 wei**
4. ยืนยันใน MetaMask เมื่อสำเร็จให้คัดลอก Address จาก **Deployed Contracts** แล้วใส่ในช่อง `address` ของ `config.js`
5. ใน GitHub ไปที่ **Settings → Pages** แล้วเลือก **Deploy from a branch → main → /(root) → Save**

เปิด frontend ในเครื่องได้จากโฟลเดอร์โปรเจกต์ด้วย `python -m http.server 8000` แล้วไปที่ `http://localhost:8000`

## ลองสาธิต

1. ใช้บัญชี A สร้างโครงการสองระยะ เช่น **ต้นแบบ 0.0002 ETH** และ **ส่งมอบ 0.0003 ETH** ผลรวมเป็นเป้าหมาย **0.0005 ETH**
2. ใช้บัญชี B สนับสนุนจนถึง 0.0005 ETH แล้วสลับเป็นบัญชี A เพื่อส่งหลักฐานของระยะแรก
3. ใช้บัญชี B โหวตอนุมัติแล้วกด **จ่ายตาม Milestone** ตรวจยอดจ่าย 0.0002 ETH ในประวัติ แล้วทำซ้ำสำหรับระยะที่สอง
4. ทดสอบคืนเงินโดยสร้างโครงการใหม่ที่เปิดรับ 2 นาที ใช้บัญชี B สนับสนุนบางส่วน รอให้หมดเวลา แล้วกด **ขอรับเงินคืน**
